# 需求单：桌面收纳盒（安卓桌面文件夹式，T-059）

> **T-060 方向修订（2026-11-16 晚，用户提问后 AI 推荐代决，可推翻）**：
> 数据模型从「虚拟引用分组」改为**文件夹门户式**——每个盒绑定一个真实文件夹，盒内条目 = 文件夹内容实时同步（QFileSystemWatcher），「文件夹变成收纳盒」= 绑定已有文件夹；新建盒的托管文件夹建在 `%LOCALAPPDATA%\PopTools\box\`（桌面不出现真实文件夹图标）。多盒支持（协议槽位扩展至 6，后注册/后画者优先命中）。尺寸规则：格子尺寸固定，拖拽吸附为列/行整数倍；条目增删自动增高（不超屏），超上限自动翻页。条目整理回归资源管理器（盒是视图不搬文件；删除文件走资源管理器回收站）。

**一句话目标**：在桌面上渲染一个「贴壁纸」的收纳盒面板（壁纸之上、图标之下），内含软件快捷方式网格，支持翻页、单击选中、双击启动，条目是虚拟引用不是真实文件夹。
**场景**：项目开发 · 新功能模块（复用日历注入架构）
**交付物**：可运行构建 + 真机目测；core/box 域 + ui/box 渲染与管理对话框 + BoxModule + SHM v2 协议 + DesktopSurface 抽取；ctest 全绿
**关键约束**：与桌面日历共存于同一共享位图；遵守性能红线（图标提取禁入主线程）；拔插=删一个目标
**验收标准**：①盒子贴壁纸显示、图标可拖过；②双击条目启动软件；③单击高亮选中；④翻页按钮工作；⑤管理界面可添加/删除/排序；⑥日历功能无回归（ctest 96+新增全绿）
