# 技术栈

## 语言与标准
- C++17（MSVC 2026，`D:\Microsoft Visual Studio\18\Community`）

## GUI 框架
- Qt 6.8.3 LTS（LGPL v3 开源版，动态链接，个人使用免费）
  - 位置：`F:\Qt\6.8.3\msvc2022_64`
  - 模块：Widgets、Gui、Core、Network
  - 架构：win64_msvc2022_64（MSVC ABI 兼容 VS2026）

## 构建系统
- CMake（`D:\CMake\bin\cmake.exe`）+ Visual Studio 生成器
- Qt 官方 CMake API：`qt_add_executable`、`qt_standard_project_setup`

## 核心功能组件
- **截图**：Qt 全屏窗口 + 鼠标事件 + `QScreen::grabWindow` / `QScreen::grab`
- **OCR**：Tesseract 5（通过命令行 `tesseract.exe` 调用，含中文语言包 chi_sim）
- **翻译**：OpenAI 兼容大模型 API（用户可配置 base_url / api_key / model，可接 DeepSeek、Ollama 等）+ 预留本地引擎接口

## 平台 API
- Windows 全局热键：`RegisterHotKey` / `UnregisterHotKey`（user32.lib）
- 系统托盘：`QSystemTrayIcon`

## Python 环境（仅辅助脚本）
- uv 创建的 `.venv`，Python 3.14，安装 aqtinstall（Qt 下载工具）
