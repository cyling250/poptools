# 文件结构

## 分层架构

采用标准 Qt/C++ 中大型项目组织：**三层分层 + 领域模块化**，引入 `snipaste` 命名空间。

```
f:\snipaste\
├── CMakeLists.txt              # 根构建：配置 + 组装可执行（链接 core/ui 两库）
├── src\
│   ├── main.cpp                # 程序入口（QApplication + MainWindow）
│   ├── app\                    # 应用层：控制器与装配（可执行目标）
│   │   ├── MainWindow.h/.cpp   # 应用控制器：托盘 + 热键 + 服务编排
│   │   └── CMakeLists.txt      # （由根 CMakeLists 直接引用）
│   ├── core\                   # 核心域：与 UI 解耦的纯逻辑（静态库 snipaste_core）
│   │   ├── CMakeLists.txt
│   │   ├── annotation\         # 标注领域
│   │   │   ├── AnnotationTypes.h   # AnnotationType / Tool 枚举
│   │   │   ├── AnnotationItem.h    # 标注数据结构
│   │   │   ├── AnnotationCanvas.h/.cpp # 画板模型（撤销/重做/命中）
│   │   │   └── AnnotationPainter.h/.cpp # 渲染 + 几何工具（绘制/缩放/距离）
│   │   ├── capture\
│   │   │   └── ScreenCapturer.h/.cpp # 多屏捕获 + DPI 坐标映射
│   │   ├── hotkey\
│   │   │   └── GlobalHotKey.h/.cpp   # Windows 全局热键封装（RegisterHotKey）
│   │   ├── ocr\
│   │   │   └── OcrService.h/.cpp     # Tesseract OCR 服务（本地离线）
│   │   ├── settings\
│   │   │   └── Settings.h/.cpp       # 设置持久化（QSettings 单例）
│   │   └── translation\
│   │       └── Translator.h/.cpp     # 翻译服务（本地/大模型 API 可配置）
│   ├── ui\                     # 界面层：窗口与交互（静态库 snipaste_ui，依赖 core）
│   │   ├── CMakeLists.txt
│   │   ├── capture\
│   │   │   ├── CaptureWindow.h/.cpp  # 截图画布：状态机 + 控制点 + 标注交互
│   │   │   └── ToolBar.h/.cpp        # 标注工具栏（工具/颜色/线宽/操作）
│   │   ├── result\
│   │   │   └── ResultDialog.h/.cpp   # 结果面板（截图 + OCR + 翻译）
│   │   ├── settings\
│   │   │   └── SettingsDialog.h/.cpp # 设置对话框
│   │   └── pin\
│   │       └── PinWindow.h/.cpp      # 贴图窗口（F3，架构预留）
│   └── resources\              # 资源（qrc 位于本目录，路径相对 qrc）
│       ├── resources.qrc
│       ├── app_icon.svg        # 托盘图标（Material Design, Apache 2.0）
│       ├── icons\              # 标注工具栏 SVG 图标
│       └── tessdata\           # 中文/英文 OCR 语言包
├── build\                      # 构建产物（CMake，VS2026 生成器）
│   └── src\{core,ui}\Release\  # 两静态库输出
├── scripts\                    # 临时/辅助 Python 脚本（uv .venv 运行）
└── .trae\rules\                # 项目规则与文档
```

## 构建目标

| 目标 | 类型 | 依赖 |
|---|---|---|
| `snipaste_core` | 静态库 | Qt6 Core/Gui/Network + user32 |
| `snipaste_ui`   | 静态库 | snipaste_core + Qt6 Core/Gui/Widgets/Svg |
| `MySnipaste`    | 可执行 | snipaste_core + snipaste_ui + qrc |

Qt SDK 由 aqt 独立安装在 `F:\Qt\6.8.3\msvc2022_64`（LGPL 开源版，与项目分离），
路径经 `QT_ROOT` 环境变量或 `-DQT_ROOT=...` 注入 CMake（三级回退）。
