# 文件结构

## 分层架构

采用标准 Qt/C++ 中大型项目组织：**三层分层 + 领域模块化**，引入 `snipaste` 命名空间。

```

│   ├── app\                    # 应用层：控制器与装配（可执行目标）
│   │   ├── MainWindow.h/.cpp   # 应用控制器：托盘 + 热键 + 服务编排
│   │   └── CMakeLists.txt      # （由根 CMakeLists 直接引用）
```

> **设计模式**：
> - **门面 + 组合 + 依赖注入**：`CaptureWindow` 是截图功能的门面（对外仅 `startCapture`/`captured`）与事件路由；选区/标注编辑/工具绘制/文字编辑/OCR/输出各为独立控制器（Controller），经 `CaptureContext`（共享状态 + 回调）注入依赖并在窗口构造时"注册"（组合），消除原"上帝类"（CaptureWindow 曾 1487 行）
> - **策略模式**：`tools\ToolBase` 抽象基类（cursor/onPress/onDrag/onRelease/paintDraft）+ 具体工具（Shape/Segment/Brush/Pencil/Doodle/Mosaic/Text/Eraser）各自实现交互，替换原 CaptureWindow 巨型 switch
> - **模板方法**：`BrushTool` 基类固化"起笔-累积笔迹-提交"生命周期，`rebuildDraft`/`commitItem` 由铅笔/涂鸦/马赛克子类定制（笔迹风格 + 线宽档位区分工具）
> - **简单工厂**：`ToolFactory::create(Tool, ToolContext*)` 按枚举创建工具实例，`None` 返回 nullptr（选择模式由窗口处理）
> - **依赖注入**：`ToolContext` 向工具注入画板/屏幕/工具栏引用与窗口回调（requestUpdate/stateChanged/buildMosaic/beginText），工具与窗口解耦
> - **单例模式**：`ToolBar::create(parent)` / `ToolBar::instance()` + 静态 `s_instance`

## 构建目标

| 目标 | 类型 | 依赖 |
|---|---|---|
| `snipaste_core` | 静态库 | Qt6 Core/Gui/Network + user32 |
| `snipaste_ui`   | 静态库 | snipaste_core + Qt6 Core/Gui/Widgets/Svg |
| `MySnipaste`    | 可执行 | snipaste_core + snipaste_ui + qrc |

Qt SDK 由 aqt 独立安装在 `D:\Qt\6.8.3\msvc2022_64`（LGPL 开源版，与项目分离），
路径经 `QT_ROOT` 环境变量或 `-DQT_ROOT=...` 注入 CMake（三级回退）。
