# 文件结构

```
f:\snipaste\
├── CMakeLists.txt          # CMake 构建配置
├── scripts\                # 临时/辅助 Python 脚本（uv .venv 运行）
│   ├── install_qt.py       # aqt 安装 Qt
│   ├── aqt_query_arch.py   # 查询 Qt 架构
│   ├── check_qt_repo.py    # 检查 Qt 仓库结构
│   └── test_proxy.py       # 代理连通性测试
├── src\
│   ├── main.cpp            # 程序入口
│   ├── MainWindow.h/.cpp   # 主窗口：系统托盘 + 全局热键控制
│   ├── CaptureWindow.h/.cpp# 截图画布：状态机（框选→编辑）+ 8控制点精调
│   ├── OcrService.h/.cpp   # Tesseract OCR 服务
│   ├── Translator.h/.cpp   # 翻译服务（本地/大模型 API 可配置）
│   ├── PinWindow.h/.cpp    # 贴图窗口（F3，架构预留）
│   ├── Settings.h/.cpp     # 设置持久化（QSettings）
│   └── resources\          # 图标与 Tesseract 语言包
│       ├── app_icon.svg    # 托盘图标（Material Design, Apache 2.0）
│       ├── resources.qrc   # Qt 资源文件
│       └── tessdata\       # 中文/英文语言包
├── build\                  # 构建产物（CMake）
└── .trae\rules\            # 项目规则与文档
```

Qt SDK 独立安装在 `F:\Qt\6.8.3\msvc2022_64`（LGPL 开源版，与项目分离）。
