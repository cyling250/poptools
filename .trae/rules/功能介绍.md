# 功能介绍

个人使用的全场景截图软件（Snipaste 替代品，规避 PRO 收费功能）。

## 核心功能
1. **区域截图**：按全局热键（默认 F1）进入截图模式，鼠标框选任意区域
2. **截图编辑标注**：矩形、箭头、文字、马赛克等基础标注
3. **OCR 文字识别**：截图后一键识别图中文字（Tesseract 本地离线，中文+英文）
4. **翻译**：对识别/输入文本调用可配置的大模型 API 翻译（支持 DeepSeek / OpenAI / Ollama 等），也可选本地引擎
5. **系统托盘常驻**：后台运行，托盘菜单控制
6. **贴图**：F3 将最近截图（带批注）贴到屏幕顶层——初始位置=截图选区，支持拖动 / 滚轮缩放 / 右键清除与销毁；张贴同时自动保存到设置中的默认文件夹

## 操作流程
```
F1 截图 → 框选区域 → 确认 → 剪贴板/结果面板
                ├── 识别文字 (OCR)
                └── 翻译 (大模型 API)
```

## 与 Snipaste 差异
- Snipaste 2.x PRO 的 OCR/翻译收费；本项目完全免费、本地 OCR、翻译 API 可自配
- 个人使用、不商用，代码可私有
